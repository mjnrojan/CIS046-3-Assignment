🏛️ Enterprise Architecture & The Four Themes

1. Virtual Identity

Bcrypt Password Hashing & Session Fixation Immunity: Implements password_hash(PASSWORD_BCRYPT) with salted 60-character hashes ($2y$ prefix, cost 12) resistant to rainbow table attacks. Authenticated logins invoke session_regenerate_id(true) to prevent session hijacking. User identity, battle Elo, and high scores persist in a relational MySQL database via PDO prepared statements.

2. Interoperability

External REST Proxy, Anti-Cheat Tokens & Sub-10ms Session Cache: Connects to the external Banana Riddle API through a secure server-side proxy (api/puzzle.php). Strips solution digits on the server to prevent client-side inspection cheats and stores a single-use token in session memory. Implements low-latency cache prefetching and an Elo matchmaking queue (pairs within $\pm$200 Elo tolerance with a 10s heartbeat TTL).

3. Event Handling

State Machine Transitions & Bidirectional Duel Synchronization: Classic Ladder manages a state machine for mistake events that chip potential points ($50 \to 35 \to 20 \to 10$). Puzzle Rush listens for strikeout events to trigger Game Over states. Puzzle Battle runs a 1.5s room synchronization loop updating opponent scores and strikes live on a dual race bar, with native DOM digit click dispatchers.

4. Version Control

Disciplined Git Feature Branching & Defense Test Harness: Developed across clear, thematic git branches (feature/banana-puzzle-arena, feature/classic-ladder, feature/puzzle-rush, feature/puzzle-battle, feature/leaderboards). Includes an automated CLI test harness with 33 passing test assertions proving every contract.
